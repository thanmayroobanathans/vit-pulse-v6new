# VIT Pulse — Heldenmunt Boys Machine

Static GitHub Pages app using Firebase Authentication (Google) and Firestore.

## Files
- `index.html` — UI
- `script.js` — quiz/classification engine
- `firebase-config.js` — Firebase Web App config
- `firebase-app.js` — Firebase initialization
- `auth-gate.js` — Google authentication + Firestore profile
- `style.css` — optional shared styles
- `firestore.rules` — Firestore security rules
- `worker.js` — optional aggregate endpoint

## GitHub Pages
Deploy from the repository root. Firebase Authentication must have Google enabled and the GitHub Pages hostname added under Authentication → Settings → Authorized domains.

For this project the hostname is `thanmayroobanathans.github.io`.
